# ScreenCraft 产品原型

## 一、界面总览

本产品包含两个主要窗口：

1. **主控制窗口** - 设置和录制控制
2. **悬浮监视窗** - 录制状态实时显示（不录入视频）

---

## 二、主控制窗口

### 2.1 窗口形态

- **位置**: 屏幕中央
- **尺寸**: 480px × 600px（固定尺寸，不可缩放）
- **样式**: 深色主题，半透明边框，圆角

### 2.2 组件说明

| 组件 | 功能 | 交互 |
|------|------|------|
| 分辨率下拉框 | 选择录制分辨率 | 点击展开选项列表 |
| 帧率下拉框 | 选择帧率 | 点击展开选项列表 |
| 系统音频复选框 | 启用/禁用系统音频录制 | 点击切换 |
| 麦克风复选框 | 启用/禁用麦克风录制 | 点击切换 |
| 保存路径输入框 | 显示保存目录 | 点击右侧按钮打开文件对话框 |
| 转MP4复选框 | 录制结束后自动转封装 | 点击切换 |
| 开始录制按钮 | 启动录制 | 点击开始/停止录制 |
| 状态栏 | 显示录制状态和时长 | 仅显示 |

### 2.3 状态变化

```
[空闲] ──点击──► [录制中] ──点击──► [暂停中] ──点击──► [录制中]
                                    │                      │
                                    └────────停止─────────┘
```

## 三、悬浮监视窗

### 3.1 窗口形态

- **位置**: 屏幕右上角（可拖动）
- **尺寸**: 200px × 120px（固定尺寸）
- **样式**: 深色半透明背景，圆角，无边框
- **特性**:
  - 始终置顶
  - 可拖动
  - **不录入视频**（使用 `SetWindowDisplayAffinity` 排除捕获）
  - 录制时显示，停止录制后3秒自动隐藏

```
┌─────────────────────────┐
│  ◉ 录制中     00:05:23  │
│  ─────────────────────│
│  分辨率: 2560×1440     │
│  帧率:   60 FPS        │
│  编码:   NVENC         │
│  ─────────────────────│
│  ⌨ 键盘: 156 次       │
│  🖱 点击: 42 次        │
│  🖼 移动: 200 Hz       │
└─────────────────────────┘
```

### 3.2 组件说明

| 组件 | 内容 | 说明 |
|------|------|------|
| 状态指示 | 绿点 + 状态文字 | 录制中(绿) / 暂停中(黄) / 空闲(灰) |
| 录制时长 | 00:05:23 格式 | 实时更新 |
| 分辨率 | 当前录制分辨率 | 如 2560×1440 |
| 帧率 | 当前帧率 | 如 60 FPS |
| 编码器 | 当前使用的编码器 | NVENC / AMF / QSV / x264 |
| 键盘计数 | 按键总次数 | 录制期间累计 |
| 点击计数 | 鼠标点击总次数 | 录制期间累计 |
| 移动采样 | 鼠标移动采样率 | 固定 200 Hz |

### 3.3 拖动交互

- 鼠标按下标题区域可拖动
- 拖动范围限制在屏幕内
- 关闭应用后记住位置，下次启动时恢复

## 四、录制流程

### 4.1 启动录制

```
用户点击"开始录制"
       │
       ▼
┌──────────────────┐
│ 1. 验证设置     │───► 错误提示
└────────┬─────────┘
         │ 通过
         ▼
┌──────────────────┐
│ 2. 启动Native   │───► 错误提示
│    Core进程     │
└────────┬─────────┘
         │ 成功
         ▼
┌──────────────────┐
│ 3. 发送start    │
│    指令         │
└────────┬─────────┘
         │ 响应
         ▼
┌──────────────────┐     ┌──────────────────┐
│ 4. 主窗口显示    │     │ 5. 悬浮窗显示   │
│    "录制中"     │     │    录制状态     │
└────────┬─────────┘     └──────────────────┘
         │
         ▼
    [录制进行中]
```

### 4.2 停止录制

```
用户点击"停止录制"
       │
       ▼
┌──────────────────┐
│ 1. 发送stop指令  │
└────────┬─────────┘
         │ 响应
         ▼
┌──────────────────┐
│ 2. 接收输出路径  │
│    (video.mkv,  │
│    actions.csv, │
│    movements.csv)│
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 3. 主窗口显示    │
│    "录制完成"   │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 4. 悬浮窗显示    │
│    "录制完成"   │
│    3秒后自动隐藏 │
└──────────────────┘
```

### 4.3 暂停/恢复

```
暂停: 点击暂停按钮
      │
      ▼
  发送pause指令
      │
      ▼
  悬浮窗状态变更为"暂停中"(黄色)
      │
      ▼
  视频暂停，事件继续记录但不计入时长

恢复: 点击恢复按钮
      │
      ▼
  发送resume指令
      │
      ▼
  悬浮窗状态变更为"录制中"(绿色)
```

## 五、异常处理与进程管理

### 5.1 进程架构

```
┌────────────────────────────────────────────────────────┐
│                    Electron 主进程                      │
│  ┌─────────────────────────────────────────────────┐  │
│  │              RecorderService                     │  │
│  │  - 子进程管理 (spawn/kill)                       │  │
│  │  - 心跳检测 (每5秒检查)                           │  │
│  │  - 自动重启 (崩溃后3秒重启)                       │  │
│  │  - 日志记录 (stderr → 文件)                      │  │
│  └─────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
                          │
                    stdio JSON
                          ▼
┌────────────────────────────────────────────────────────┐
│                  recorder_core.exe                      │
│  - OBS录制引擎                                         │
│  - 输入事件捕获                                         │
│  - CSV文件写入                                          │
└────────────────────────────────────────────────────────┘
```

### 5.2 进程保护机制

| 场景 | 处理方式 | 用户反馈 |
|------|----------|----------|
| Native Core 意外退出 | 3秒后自动重启进程 | 悬浮窗显示"连接中断，正在重连..." |
| Native Core 崩溃 | 记录错误日志，重启进程 | 弹出错误提示，显示错误原因 |
| 主进程异常退出 | Native Core 随主进程一起退出 | - |
| 录制中异常退出 | 下次启动时检查临时文件 | 提示是否恢复未完成的录制 |

### 5.3 心跳检测

```
Native Core ──每3秒──► 心跳消息 ──► 主进程
                                       │
                              ┌────────┴────────┐
                              │                │
                         超时(<3s)         正常
                              │                │
                              ▼                │
                     判定为崩溃/无响应          │
                              │                │
                              ▼                │
                     3秒后重启Native Core       │
```

### 5.4 日志管理

- **位置**: `%APPDATA%/ScreenCraft/logs/`
- **格式**: `recorder_YYYYMMDD_HHMMSS.log`
- **内容**:
  - 启动/停止时间
  - 错误和异常
  - 配置参数

## 七、快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+R` | 开始/停止录制 |
| `Ctrl+Shift+P` | 暂停/恢复录制 |
| `Esc` | 停止录制并退出（录制中时） |
